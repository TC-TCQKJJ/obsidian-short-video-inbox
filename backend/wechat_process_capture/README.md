# WeChat Process Capture Helper

This Windows-only helper uses SunnyNet's process driver to observe
`WeChatAppEx.exe`. It loads the per-machine CA generated by the Python capture
host and sends narrowly filtered capture events to the authenticated loopback
bridge on `127.0.0.1:2024`.

Security constraints:

- It never embeds or installs `SunnyRoot` or another shared private key.
- It does not call `Sunny.Start()`, set the system proxy, or open a proxy
  listener.
- Only the explicit WeChat Channels host allowlist is decrypted. Other traffic
  from the WeChat process is forwarded as raw TCP.
- Only safe request headers are sent to the Python matcher.
- Driver startup failure is fatal; there is no fallback to a system proxy.

The helper requires administrator privileges only for starting the process
driver. The Python UI launches it through `launch-process-capture.ps1`.
